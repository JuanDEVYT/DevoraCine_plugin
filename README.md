# DevoraCine — Plugin para Kino

Plugin no oficial para el catálogo de [devoracine.com](https://devoracine.com/). Identidad visual basada en la web: verde bosque `#132505`, rojo vino `#C32424` y su icono oficial.

## Versión 1.0.0

- Búsqueda y catálogo de Devoracine.
- Fichas enriquecidas mediante `kino.meta` cuando está disponible.
- Resolución HLS directa cuando el reproductor externo la expone.
- Log de inicio: `[DevoraCine v1.0.0] Creado por JuandreXter`.
